# 开源治理、依赖与知识产权边界

## 维护方式

项目版权与许可见 [MIT LICENSE](../../LICENSE)。仓库负责人维护路线图、审核合并并发布版本；贡献者通过 Issue / Pull Request 参与。技术取舍和兼容性影响应留在对应 Issue / PR 中，不能只存在于私人聊天。

问题报告应包含运行平台、版本、复现步骤、预期与实际结果；文档样本必须脱敏。维护者按数据丢失/安全风险、功能阻断、体验问题排序处理，在有能力维护的时间内回复，不承诺尚无资源保障的固定 SLA。安全问题按 [SECURITY.md](../../SECURITY.md) 私下报告。贡献要求见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

修改规则需提供命中例、合理用法和 Markdown 边界样例。模型与文件工具变更需覆盖错误、预算、路径边界和用户确认；发布前运行回归测试、前端测试及生产构建。新贡献不应提交密钥、工作区私有正文、生成的安装目录或第三方未授权语料。

## 依赖清单

| 组件 | 用途 | 锁定与追溯 |
|---|---|---|
| Python 标准库 | 核心扫描、文件处理、模型 HTTP 适配 | Python 版本见 CI 和包的构建清单 |
| pywebview | 桌面窗口与本地桥接 | 版本范围见 `pyproject.toml`，实际版本见 `.build.json` |
| PyInstaller | 应用打包 | 仅构建用途，实际版本见 `.build.json` |
| Vue 3 | 前端工作台 | 版本与传递依赖见 `desktop-ui/pnpm-lock.yaml` |
| Vite / Vue 插件 | 前端开发与生产构建 | 版本见同一 lockfile |
| pytest | Python 测试 | 测试用途，范围见 `pyproject.toml` |
| lark-cli（可选外部安装） | 飞书访问 | 不打入桌面包，用户按自身账号授权 |
| 用户选择的模型服务 | 在线语义审查 | 服务条款、模型许可与 API 使用限制由该提供方决定 |

项目 MIT 许可不替代第三方组件许可或用户文档版权；构建脚本将已安装 Python 与前端依赖的许可证和声明文件收集到应用的 `third-party-licenses` 资源目录（也包含部分构建工具，属于运行时依赖的超集）。每次发行同时提供构建包版本清单，审查具体分发依赖时以实际产物为准。不要将代码开源宣称为模型服务、训练数据或评测文档全部开源。

## 数据及事实质量

静态扫描在本地执行。在线 Agent 将待审查内容及用户允许的资料片段发送给所选模型服务。API Key 仅用于当前进程调用；任何验证记录均不得包含密钥或私有文档正文。公开 demo 使用仓库内可分发的样例，性能测试需说明使用的是模拟传输还是真实外部服务。

Agent 输出属于修改建议。作者保留事实核对和最终接受权；工作区资料冲突或缺失时应保留查证状态，不以流畅改写替代证据。真实用户部署规模、质量收益、社区成员数与维护能力只依据实际记录陈述，不编造市场数据。
