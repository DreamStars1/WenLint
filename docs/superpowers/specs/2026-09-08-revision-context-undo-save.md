# 修改稿核对与保存规格

## 用户目标

让用户能理解每一处自动改写、结合原文上下文决定是否采用，并清楚地区分覆盖原文件和保存新副本。

## 验收要求

- 每条 REWRITE 变更展示规则名称、修改原因、原文和建议文本；模型独立发现的问题保留来源标识。
- 用户可逐条撤销或恢复修改，修改稿立即按当前选择重新生成。
- 全文核对页提供上一处/下一处导航，显示当前改写附近的原文上下文、修改原因和建议文本。
- 全文核对内容只读，避免手工编辑与逐条撤销产生冲突；需要继续编辑时使用“应用到编辑区”。
- “保存”覆盖通过原生文件对话框打开的文件或当前工作区文件，并在覆盖前再次确认。
- 覆盖写入必须校验打开/读取时的 SHA-256；检测到外部修改时拒绝写入，并使用同目录临时文件原子替换。
- “另存为”保持独立，通过系统保存对话框创建新文件。
- 粘贴和拖入的文本没有可信原文件句柄，只允许另存为。
