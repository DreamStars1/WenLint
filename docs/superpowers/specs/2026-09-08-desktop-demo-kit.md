# 桌面版演示包规格

## 用户目标

提供一套开箱即用的材料，能够说明 WenLint 当前桌面版的完整用法，并让演示者区分确定性结果与受模型影响的结果。

## 验收要求

- 提供一份可通过“打开文件”载入的 UTF-8 待审查文档，覆盖套话、模糊词、过程痕迹、上下文依赖、冗余、重复和产品标题结构问题。
- 提供一个可直接关联的工作区；工作区包含待审查文档、事实基线和验收实测记录。
- 提供明确的演示步骤，覆盖本地检查、模型配置、语义复核、修改原因、全文上下文、撤销/恢复、保存和另存为。
- 明示当前工作区只向模型发送路径索引，不宣称模型会自动读取其他文件正文。
- 提供机器可验证的静态结果快照和脚本；脚本还要验证独立文档、工作区副本及索引结构没有漂移。
- 提供语义复核人工验收清单和一份事实一致、可通过 WenLint 本地检查的参考修改稿。
- 所有业务内容均为虚构材料，不含 API Key 或真实个人/业务数据。
