# WenLint 桌面版演示包

这套材料用于完整演示 WenLint 0.5.0：打开待审查文档、关联工作区、运行本地检查和语义复核、核对修改原因与上下文、撤销单项改写，以及区分“保存”和“另存为”。文档中的产品、日期和指标均为虚构数据，不包含真实凭据。

## 启动

在本仓库根目录执行 `./demo/start-demo.ps1`。脚本会依次查找随演示包放置的 `WenLint.exe`、仓库根目录下的 EXE、`dist-0.5.0-final/WenLint.exe` 和标准构建目录 `dist/WenLint.exe`，并启动找到的版本。

若这些位置都没有 EXE，请先从项目 Release 下载 Windows 构建并放入 `demo` 目录，或运行 `./scripts/build-windows.ps1` 本地构建。演示材料本身不把大型二进制提交到 Git。

## 快速演示（约 5 分钟）

1. 启动 WenLint，在“场景”中选择“产品 / PRD”。
2. 点击“打开文件”，选择本目录的 `review-me.md`。
3. 点击“本地检查”。应发现套话、术语滥用、模糊词、讨论/纠偏过程痕迹、旧上下文依赖、冗余、重复词和标题编号断层等候选问题。
4. 在“设置”中填写受信任模型服务的 Base URL、API Key 和模型名称，点击“语义复核”并确认发送。
5. 在“复核结论”中区分 KEEP、REWRITE、VERIFY、ASK；在“修改稿”中查看每处修改原因。
6. 打开“全文核对”，使用左右箭头检查原文上下文，尝试“撤销这处修改”和“恢复这处修改”。
7. 点击“另存为”生成新文件。若要演示“保存”，请先复制 `review-me.md`，再打开副本；确认后会覆盖该副本，文件被外部改动时会拒绝覆盖。

## 工作区演示

1. 点击顶部“工作区”，选择 `demo/workspace` 目录。
2. 复核前先从左侧阅读 `evidence/product-baseline.md` 和 `evidence/acceptance-results.txt`，记下日期、平台、超时值和性能结果；也可以用外部编辑器并排打开它们。
3. 从左侧打开 `review-me.md`，运行本地检查和语义复核，再依据已查看的材料人工核对 VERIFY / ASK 项。
4. 修改正文后，“写回工作区”会要求再次确认，并在写入前校验文件哈希。

当前版本的工作区语义复核会发送当前文档正文和工作区相对路径索引，不会自动读取其他文件正文。打开另一工作区文件也会清空当前检查结果，因此应在复核前阅读依据，或使用外部编辑器并排核验；不应宣称模型已经自动读取了这些依据。

## 可重复验证

在仓库根目录运行：

```powershell
python demo/verify_demo.py
```

该命令可直接从源码运行，无需预先安装 WenLint。脚本会验证独立文档与工作区副本一致、工作区索引精确匹配固定清单，并将产品场景下的静态检查结果与固定快照逐项比较。语义复核受模型影响，人工验收标准见 `evidence/semantic-review-checklist.md`，一份可接受的最终稿见 `evidence/expected-revision.md`。
